# Tongjiang Lab — химия на русском

25 автономных интерактивных 3D-уроков химии на русском языке: опыты, модели, пошаговые объяснения и задания.

Сайт: **[chemistry.kk-minsk.by](https://chemistry.kk-minsk.by)**. Публичный репозиторий: [envOnion/chemistry-lab-ru](https://github.com/envOnion/chemistry-lab-ru).

Это русская адаптация [Tongjiang Lab](https://lab.tongjiang.app). Из исходного набора оставлены уроки химии; уроки физики, биологии и географии и их обложки удалены. В HTML переведены интерфейс, пояснения, задания, подсказки, подписи моделей и справочные тексты. Содержание по-прежнему соответствует китайской программе старшей школы и учебникам PEP 2019, а не отдельной российской программе.

## Как открыть

1. Откройте [index.html](index.html) в Chrome или Edge.
2. Выберите урок. Кнопка «Каталог» внутри урока возвращает к этому списку.
3. Проходите шаги, меняйте параметры и открывайте выводы. Стрелки клавиатуры переключают шаги; остальные сочетания приведены в разделе «Управление» каждого урока.

Каждый файл `courses/*.html` также можно открывать отдельно. Код, оформление и Three.js встроены в файл; подключение к интернету, сервер, установка пакетов и сборка не нужны. Чтобы работала кнопка возврата к каталогу, сохраняйте структуру папок. Для 3D нужен браузер с поддержкой WebGL.

## Состав репозитория

- `index.html` — локальный каталог на русском.
- `courses/` — 25 самостоятельных HTML-уроков.
- `covers/` — 25 оригинальных обложек уроков химии.
- `catalog.json` — русские названия, вопросы, шаги, ссылки на файлы и привязка к исходным учебникам. Поле `source_url` ведёт на оригинальную страницу автора; язык локальных уроков указан в `language`.

Русские тексты встроены в HTML. Для подготовки использован автоматический перевод с ручной правкой интерфейса, химических терминов и ключевых объяснений. Онлайн-переводчик при просмотре не используется. Верстка адаптирована для более длинных подписей; расчётная логика экспериментов сохранена. Отдельного проекта сборки и штатного набора автоматических тестов в исходном репозитории нет.

## Публикация через Coolify

Приложение использует публичный репозиторий `envOnion/chemistry-lab-ru`, ветку `main` и `Dockerfile` в корне. Внутренний порт — `80`, проверка здоровья — `GET /healthz`. Домен: `https://chemistry.kk-minsk.by`. TLS и перенаправление HTTP на HTTPS обеспечивает Coolify. База данных и переменные с секретами не нужны.

Образ Nginx закреплён по digest. В него копируются только каталог, уроки, обложки и лицензии; HTML и JSON передаются со сжатием gzip. После обновления `main` новую версию можно опубликовать кнопкой Redeploy в Coolify.

Для проверки контейнера: `docker build -t chemistry-lab-ru .`, затем `docker run --rm -p 8080:80 chemistry-lab-ru`. Каталог будет доступен по адресу `http://localhost:8080`, проверка здоровья — `http://localhost:8080/healthz`.
